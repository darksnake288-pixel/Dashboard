# Dashboard

Static dashboard UI built with HTML and Tailwind CSS. Includes a top navbar (logo, links, sign-in / mobile menu) and a responsive grid of content cards.

**Live pages:** [github.io/Dashboard](https://darksnake288-pixel.github.io/Dashboard/)

## Features

- Full-width header with navigation
- Sign-in button on larger screens and a menu icon on small screens
- Responsive card grid (1–5 columns by breakpoint)
- Tailwind CSS via CDN (no build step)

## Stack

- HTML5
- Tailwind CSS 4 (browser CDN)

## Run locally

```bash
git clone https://github.com/darksnake288-pixel/Dashboard.git
cd Dashboard
python3 -m http.server 8080
```

Open `http://localhost:8080`, or open `index.html` directly in a browser.
